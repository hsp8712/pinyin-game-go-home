# 拼音回家大冒险

适合约 7 岁儿童和家长、老师一起玩的拼音网页游戏。手机、平板、电脑均可使用。

产品需求见 [docs/PRD.md](docs/PRD.md)。

## 本地运行

需要 Node.js 22 或以上版本。应用没有运行时第三方依赖。

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173 。如需在同一局域网的手机或平板上测试，可使用电脑的局域网 IP 和端口 5173；设备需能访问该端口。

```bash
npm run build
npm run preview
```

静态产物位于 `dist/`，可部署至支持静态文件的 HTTP/HTTPS 托管服务。请通过网页服务器打开，不能直接双击 HTML 文件。

## 功能

- 声母、韵母、整体认读音节、声调、音节拼读、自选六种模式。
- 回家、过河、爬山三种场景；小兔、小熊、小狐狸三种本地 SVG 角色。
- 每局 1～20 个拼音，3～10 格路程；默认 4 个拼音、3 格。
- 默认均衡随机，可选普通随机；已到终点的拼音退出抽取。
- 人工记录独立完成、自我纠正、提示后完成、暂未完成四种表现。
- 默认不后退，可由家长在孩子愿意的前提下开启后退挑战。
- 单步撤销、暂停、刷新续玩、胜利结算、家长记录与待加强项选练。
- 支持键盘基本操作、对话框焦点管理、系统或手动减少动画。

应用不录音、不自动识别或评分、不提供示范音频。需要时由陪练者口头示范。

## 数据与实现

全部练习数据保存在当前浏览器的 localStorage 中，键名为 `pinyin-adventure-v1`，没有后端或账号。保存一局进行中的冒险及最近 100 局历史记录。手机、平板和电脑之间不自动同步，清理浏览器数据会丢失记录。多标签页检测到外部写入时暂停当前页保存，避免静默覆盖。

- `src/data.js`：静态拼音题库、场景与评分配置；发布题库变更前需复核拼写、声调和拼读结构。
- `src/engine.js`：独立游戏状态转换、抽取、评分、撤销、统计与保存。
- `src/app.js`：页面、交互、对话框与本机进度。
- `src/scenery.js`、`src/mascot.js`：本地 SVG 棋盘与插画，无远程素材依赖。
- `src/styles.css`：手机、平板、电脑响应式布局。

## 测试

```bash
npm test
npx playwright install chromium
npm run test:e2e
```

若使用已有的 Chromium，可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指向其可执行文件。

规则测试覆盖随机抽取、移动边界、防重复评分、撤销、挑战关闭、统计和保存。浏览器测试在桌面 1440×1000、平板 820×1180、手机 390×844 三种视口下验证选题、通关、续玩、求助、挑战、记录、键盘对话框、存储异常和页面溢出。

自动化视口测试不等同于真实设备或 Safari/Edge 兼容性验收。PRD 中的真实设备验证和 5～8 组亲子试玩仍需安排；不以通关或使用时长宣称学习效果。
