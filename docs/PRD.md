# 《拼音回家大冒险》产品需求文档 PRD · V1.2

状态：已确认，作为首版实现与验收依据。

## 一、产品定位与设计原则

面向约 7 岁儿童的拼音练习网页游戏，手机、平板和电脑均可通过浏览器游玩。孩子朗读，家长或老师给予帮助并记录表现，让拼音角色从 A 点逐步走到 B 点。

通过冒险故事、直观进度和适度挑战，支持认读、声调和拼读练习。

核心目标：

- 孩子愿意开口，遇到困难后仍愿意尝试。
- 大人可以配置学习内容，并了解哪些条目需要帮助。
- 每次练习都有可见进展，能够随时暂停、以后继续。
- 三类设备具备完整、一致的游戏功能。

设计原则：

- 默认不扣除已有进度，不把读错设计成惩罚。
- 肯定自我纠正，允许主动求助。
- 保留全部到达的胜利目标，同时允许有成就感地暂停。
- 不设置倒计时、排行榜或连续练习压力。
- 游戏通关表示完成本局任务，不代表已经掌握相关拼音。

首版不提供示范音频、录音、语音识别、自动评分、账号或云端同步；需要时由陪练者口头示范。

## 二、学习内容与场景

### 2.1 学习模式

| 模式 | 内容 | 练习方式 |
| --- | --- | --- |
| 声母 | 单个声母 | 看卡片认读 |
| 韵母 | 单韵母、复韵母、鼻韵母 | 按分类选择并认读 |
| 整体认读音节 | 整体认读音节 | 看卡片认读 |
| 声调 | 带不同声调的音节 | 默认四声，轻声可选 |
| 音节拼读 | 两拼、三拼音节 | 展示完整音节，可展开拼读结构 |
| 自选练习 | 跨分类选择题库内容 | 组合课堂内容或需要巩固的条目 |

内容要求：

- 使用人工校对的题库，不自动生成未经校对的音节。
- 音节拼读提供无调和带调条目，声调模式使用带调音节。
- 同一条目在一局内只出现一次，不同声调分别作为条目。
- 自选练习采用题库勾选，首版不开放自由输入。
- 字体清楚显示 ü 和声调符号。
- 首次使用建议先练单一分类，跨分类混合由大人主动选择。

### 2.2 冒险场景

| 场景 | 起点 → 终点 | 到达反馈 |
| --- | --- | --- |
| 带拼音回家 | 森林入口 → 温暖小屋 | 点亮房间 |
| 带拼音过河 | 河岸 → 对岸营地 | 在营地集合 |
| 带拼音爬山 | 山脚 → 山顶观景台 | 插上小旗 |

默认“带拼音回家”，三种场景共用规则，不改变学习难度。提供三种陪伴角色外观，不影响规则。

故事表达为“陪拼音朋友走一段路”，角色可以安全休息。不出现掉水、坠落、受伤、哭泣或因孩子读错而被困的情节，不使用制造亏欠感的文案。

装饰和动画不得遮挡拼音或干扰朗读。

## 三、配置与核心玩法

### 3.1 开始游戏

首页提供“开始新冒险”“继续上次冒险”和“家长练习记录”。

配置分为两步：

1. 大人设置任务：选择模式、拼音、路程、抽取方式和挑战规则。
2. 孩子参与准备：选择场景与陪伴角色，点击出发。

规模设置：

- 每局支持 1～20 个拼音。
- A 到 B 支持 3～10 格。
- 首次预填 4 个拼音、3 格路程，可自由修改。
- 支持分类全选、清空和随机选取。
- 开始前显示“本局 N 个拼音，路程 D 格”，不承诺固定完成时间。
- 未选择拼音时不能开始，并提示原因。

初始规模是待试玩验证的默认值，不作为儿童注意力时长标准。

### 3.2 抽取方式

| 方式 | 规则 |
| --- | --- |
| 均衡随机，默认 | 将未到终点的拼音打乱，每个练一次，再开始下一轮 |
| 普通随机 | 每次从未到终点的拼音中等概率抽取，允许连续抽中同一个 |

均衡随机在新一轮有多个候选项时，避免首项与上一轮末项相同。

暂时不会的条目完成记录后进入后续练习，不在同一回合反复追问。仅剩一个条目时，可以继续，也可以暂停。

### 3.3 单次练习

抽取拼音 → 孩子朗读或求助 → 大人记录表现 → 角色移动 → 手动开始下一次。

孩子可以选择：

- 我再试一次：保持当前条目，允许自行修正。
- 请帮帮我：提示陪练者给予口头帮助。
- 休息一下：保存进度，进入休息状态。

这些入口不直接评分，不扣除进度。每回合由大人最终提交一次结果。

### 3.4 默认评分与移动

| 表现记录 | 移动 | 反馈示例 |
| --- | --- | --- |
| 独立完成 | 前进 2 格 | 这次你自己读对了！ |
| 自我纠正后完成 | 前进 2 格 | 你发现并改对了！ |
| 提示后完成 | 前进 1 格 | 一起练过，继续前进！ |
| 暂未完成 | 原地休息 | 先休息，稍后再试。 |

判断口径：

- 独立完成：无针对本题的提示，读出了本次要求的读音。
- 自我纠正：在大人提供针对性提示前，自行发现并修正。
- 提示后完成：接受提示、示范或跟读帮助后完成。
- 暂未完成：帮助后仍有困难，或本次选择暂不继续。

评分按钮同时显示表现与位移，不只依赖颜色。首次使用向大人提供简短说明，鼓励具体反馈，避免羞辱、人格评价和同伴比较。

### 3.5 可选挑战规则

家长可在开局前主动开启“后退挑战”：

- 仅将“暂未完成”改为后退 1 格，其余不变。
- 开局前说明规则，并确认孩子愿意参与。
- 局中可关闭，关闭后不恢复已发生的后退，本局不能重新开启。
- 后退动画保持角色安全，不附加失败、扣奖或负面表情。

挑战默认关闭，不作为更优秀的标志。

### 3.6 位置与操作规则

- A 点为 0，B 点为 D，位置限制在 0～D。
- 超过终点的移动直接到达 B 点。
- 在 A 点后退仍留在 A 点，保留表现记录。
- 到达终点后退出抽取池；全部抵达即胜利。
- 不设置失败条件、强制练习次数或最低速度。
- 移动期间禁止重复提交评分。
- 支持撤销最近一次评分，同步恢复位置、抽取状态和统计。
- 胜利页也可撤销最后一次评分，返回游戏。

## 四、多设备体验

### 4.1 通用要求

- 手机、平板、电脑均可完成选题、练习、评分、暂停、续玩和查看记录。
- 使用响应式网页，根据可用空间调整布局。
- 手机和平板支持触控；电脑支持鼠标和键盘基本操作。
- 核心操作不依赖悬停、拖拽或复杂手势。
- 不强制横屏，切换方向或调整窗口大小不丢失状态。
- 按钮具备清楚的文字、选中状态和键盘焦点；提交动作防重复。
- 动画简短，支持减少动画，状态同时通过文字和位置体现。

### 4.2 各设备布局

| 设备 | 布局重点 |
| --- | --- |
| 手机竖屏 | 当前拼音与核心操作优先，棋盘紧凑展示，详细列表按需展开 |
| 手机横屏、平板 | 根据空间并排展示棋盘和练习卡，空间不足时上下排列 |
| 电脑 | 棋盘与练习操作并排展示，设置合理内容宽度，避免按钮和文字分散 |

当前拼音保持大字突出，高亮对应角色。路线显示 A/B 点和“已到达 X / N”。

同格角色使用数量标记，点击或触控后查看列表；同时提供全部拼音的位置列表。

电脑端支持 Tab 移动焦点、Enter 或空格激活按钮。首版不提供易误触的单键评分快捷键。

## 五、暂停、结束与记录

### 5.1 安全暂停与完整胜利

游戏中始终提供“在这里扎营，稍后继续”。

暂停后展示本次练习次数、取得进展的拼音和保存状态，提供“继续冒险”“返回首页”。暂停不标记为失败，不清除进度，不使用催促完成的文案。

存在未完成冒险时，新开一局需确认替换；暂停和退出无需确认。

全部抵达后展示简短庆祝、帮助过的拼音和出现过的自我纠正，提供“再玩一局”“返回首页”。

“再玩一局”保留配置，位置归零。家长可进入本局记录，选择需要帮助的条目创建新局。

### 5.2 本机保存

- 使用浏览器本地存储，无需登录。
- 保存一局进行中的冒险和最近 100 局记录。
- 保存配置、位置、当前条目、抽取队列、操作阶段和挑战状态。
- 抽取、评分、撤销、暂停及关闭挑战后立即保存。
- 恢复时保持当前条目，不重新抽题或重复计分。
- 替换未完成冒险时，保留已提交的练习记录。
- 超限删除最早的历史局，进行中的冒险不受影响。
- 保存失败时持续提示无法保证续玩，允许继续当前游戏。

多设备保存边界：所有设备都能玩，但记录仅属于当前设备、当前浏览器；首版不支持手机、平板和电脑之间同步进度。清理浏览器数据可能导致记录丢失。

### 5.3 家长记录与待加强项

儿童主界面不显示薄弱率、错误排名或掌握率。详细记录通过家长入口查看，该入口不作为身份认证或隐私隔离机制。

支持“最近 7 天”和“全部记录”，默认最近 7 天。每个条目显示练习次数、四种表现次数、最近练习时间，以及需要帮助的比例：

需要帮助的比例 =（提示后完成次数 + 暂未完成次数）÷ 总有效评分次数。

- 自我纠正不计入需要帮助次数。
- 不足 3 次标记“记录较少”，不进入排序。
- 至少 3 次且出现过需要帮助时，进入待加强列表。
- 依次按需要帮助的比例、暂未完成次数、最近练习时间降序排列。
- 同一标准条目跨模式汇总，不同声调分别统计。
- 每回合仅计一次最终表现，撤销同步移除统计。
- 挑战中的后退仍记录为“暂未完成”。
- 支持勾选条目创建新局，最多 20 项。

页面说明：“记录来自陪练者的手动判断，用于安排后续练习；游戏到达不等于已经掌握。”

## 六、验收与试玩验证

### 6.1 功能与兼容性验收

- 六种模式、三种场景均可完成完整流程。
- 默认无后退，自我纠正与独立完成获得相同步数。
- 两种抽取方式符合规则，到达条目不再被抽取。
- 求助、重试不直接产生评分或统计。
- 边界处理、同格展示、撤销与胜利结算正确。
- 连续点击、刷新和恢复不重复计分。
- 暂停后可恢复相同条目与抽取队列。
- 挑战默认关闭，局中关闭后不能重新开启。
- 统计正确区分四种表现。
- 手机、平板与电脑均能完成全部核心流程，无关键内容遮挡或页面级横向溢出。
- 横竖屏切换、窗口缩放不改变游戏状态。
- 触控、鼠标和键盘基本操作均可用。
- 在 iOS/iPadOS Safari、Android Chrome，以及 Windows/macOS Chrome、Edge 的验收时最新稳定版验证；macOS 另验证 Safari。
- 验证各设备独立保存与恢复，并明确提示不支持跨设备同步。
- 存储失败有明确反馈。

### 6.2 儿童体验验证

首轮邀请 5～8 组亲子，每组至少体验两次，整体覆盖手机、平板和电脑。记录用于发现问题，不据此宣称学习效果。

重点观察：

- 是否理解目标并主动抽取。
- 遇到困难后是否愿意重试或求助。
- 是否出现持续沉默、争论评分、急于结束等反应。
- 是否接受暂停，而非认为自己失败。
- 第二次是否愿意再玩。
- 家长是否理解四种表现的区别。
- 不同设备上是否容易看清拼音、找到按钮并完成操作。

优先验证默认的 4 个拼音、3 格路程与均衡随机。若频繁出现疲劳、等待或受挫，优先减少任务量、缩短反馈并改善帮助流程。

### 6.3 首版边界

聚焦单个孩子与陪练者共同使用，完成“选题—练习—获得帮助—推进—暂停或通关—回顾记录”的闭环。

不包含班级管理、多人竞赛、广告、付费奖励、自动评分、账号、云端同步或自动安排复习。
